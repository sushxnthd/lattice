# K-SYNTH-1 / Run134 — preregistered captured-dependency discriminator

Status: development protocol only; no capable-model inference or breakthrough claim.

**Causal intervention.** Versioned dependency/state graph versus ordinary Python SSA with explicit indexed dependency/owner annotations. Both views expose the same current and historical semantic facts, protected outputs, and edit authority. Both emit the same JSON root-expression patch into the same `FramedProgram.edit` compiler and independent verifier, with identical 4096-token context and 192-token completion caps.

**Critical counterfactual design.** For each randomized program, freeze two *header-identical* multi-file Boolean-policy twins. Their historical captured upstream expressions differ, while their current first-stage root expression, public request, allowed patch targets, inputs, and owner facts match. The correct repair therefore differs. Any solver ignoring the representation must fail at least one twin. Explicitly retain this twin-pair as the cluster unit. Do not reuse the contaminated Run131/132 holdout.

**Primary endpoint.** Mean within-cluster difference in first-attempt exact semantic repair success (graph minus indexed Python), with failures retained. Only model responses are scored, never post-hoc repaired. Randomize view order and pair order; record prompt/completion tokens and raw transcripts.

**Falsification.** Python matches or exceeds graph; or advantage disappears under information-preserving graph adjacency-layout ablation. Strongest alternative explanation: ordering/visual salience, not structural localization.

**Mechanism prediction (frozen).** Graph advantage should be larger at >=4 captured-dependency edges than at 2, and disappear when historical capture is absent. Holdout remains unopened until mechanism and primary analysis are fixed.

**Publication threshold.** Not achievable on synthetic twins alone. Require independently sourced realistic multi-file issues, cluster-aware power, capable models, independent evaluator, prior-art audit, ablation, prospective holdout, uncertainty and clean reproduction.

**System consequence.** Preserve immutable historical captures in a shared compiler; expose a graph-first interface only if the representation-specific effect survives the strongest indexed-Python control and adjacency-layout ablation.
