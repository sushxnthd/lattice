## Active kernel
Question: does explicit versioned semantic structure reduce repair complexity for capable coding agents relative to Python with identical compiler, verifier, authority, and semantic facts?
Baseline: Python patch with identical FramedProgram and Run62 independent oracle.
Intervention: display the explicit versioned dependency graph as the focused view.
Matched-information control: display the equivalent lowered Python view, with the exact same canonical context supplied to both. Both arms must emit the same Python-dictionary patch syntax; no arm-specific parsing or repair feedback. Token parity must be checked before inference.
Primary scalar: paired independently correct repair within two calls, with complete tasks as denominator.
Strongest alternative: redundant view salience, token length, task triviality, model inability or verifier feedback.
Decisive falsification: no repeatable advantage after format normalization, solvability calibration, independent evaluator and unseen multi-file tests.
Publishable threshold: prior art, frozen realistic tasks, same-compiler and executable-state-machine controls, two capable models, uncertainty, adversarial ablations, unseen prediction and reproduction.
Product threshold: >=10% fewer repair calls or >=10 percentage-point hidden-test recovery without additional protected-state violations.
Kill: three substantive capable-model comparisons without a surviving effect or sharp boundary. Blocked inference is not a negative experiment.
Backups: verifier-only effect; provenance-bound semantic diff.
