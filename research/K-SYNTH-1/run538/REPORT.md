# Run538: hash-before-execution TOCTOU counterexample

Eight deterministic subprocess fixtures compare a path executed after its hash is recorded with a private byte-for-byte snapshot executed after the same mutation. Eight of eight assertions pass. Six of eight mutations change the frozen hash; one stable and one same-byte control do not. A hash recorded before executing a mutable path does not authenticate the executed bytes. A private snapshot retains the frozen bytes across these mutations, under a trusted filesystem and interpreter assumption. This is not an OS-level sandbox: copying is not atomic against concurrent mutation, and Python can import other mutable code. The experiment does not qualify a real repair, prove semantic soundness, or compare model representations.
