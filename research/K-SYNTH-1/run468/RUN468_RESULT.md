# Run468: repository-aware null calibration (synthetic)

Fixed RNG seed 4682026; 300 null replicates per condition, 100 repositories x 6 issues, discordance probability .30; 199 repository-sign randomizations per replicate. All discordant outcomes symmetric under null. Independent issue signs: exact two-sided McNemar/binomial rejects 12/300 (4.0%), cluster sign permutation 9/300 (3.0%). Shared repository direction: naive rejects 61/300 (20.33%), cluster sign permutation 14/300 (4.67%). Mean discordants 180.50 and 179.40 respectively. Monte Carlo uncertainty is substantial (300 replicates); this is a diagnostic, not a precision calibration. Repository sign randomization requires joint sign symmetry at repository level, not guaranteed in observational repairs. No actual model outputs, new qualified repairs, or representation superiority. Existing two qualified tasks unchanged; all 89 sealed issues untouched. Run code and raw JSON in local SHA-verified reproducibility bundle. This result extends Run467 with an explicitly cluster-aware comparator.
