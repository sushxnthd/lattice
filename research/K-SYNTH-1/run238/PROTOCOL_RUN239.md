# Run239: prospective functional multi-file study gate

**Status: protocol proposal, not a frozen cohort or executed inference.**

Before any new model completion, freeze each real repository's commit, exact issue statement, authorized paths/targets, source facts and prompt hashes. Exclude the previous 12 pilot issues and keep the 89 reserved boundary issues sealed.

A task qualifies only when an independently executable issue-level oracle **fails on the pinned baseline, passes a separately authored reference repair, and rejects at least two seeded defective repairs**. Preserve stdout/stderr, environment and dependency pins. For a multi-file competence claim, require at least one qualified positive-control repair actually modifying 2+ files, not merely multi-file permission.

Create one canonical source-facts object. Render it as semantic IR and literal Python source, and prove exact round-trip equality. Both arms must receive the same task facts, edit authority, common transactional compiler, verifier, action grammar, model, seed, temperature, output budget and repair-loop policy. Freeze byte-identical requests except for the representation payload and the minimal description needed to identify it. Randomize arm order. The Python source view is a **representation** baseline with shared structured edit output; do not call it an unrestricted native-Python editor.

Use complete independent issue-oracle success after an accepted transaction as the binary primary outcome. Keep compiler acceptance, Git patch application, symbol/descriptor contract failures, changed-file counts, semantic churn and token usage as secondary outcomes. Treat NOT_EVALUATED as missing, never as a failed repair. Enforce identical byte-faithful patch application and safety contracts in both arms.

Compute paired sample size from prospective discordance, effect size and repository ICC. Run238's exact independent-pair calculation gives ~80% power at 306 pairs only under discordance=.30, conditional IR win=.65 and independence; repository clustering makes this optimistic. For the smaller hypothetical .60 advantage, Run234's cluster-aware simulation suggested ~1,089 issues across ~440 independent repositories. The 258-pair direction is not inherently adequately powered.

Retain every raw request, response, model ID/hash, seed, token count, source snapshot, patch, compiler/verifier trace, independent test result, error, and SHA-256 manifest. When persistence or inference infrastructure fails, keep local artifacts and retry without altering the frozen protocol.

**Pivot rule:** If Python matches/beats IR in two well-controlled prospective functional reformulations, pivot to transactional edit safety and reliability rather than cosmetically redesigning syntax. If IR wins, preregister and test a mechanism ablation and at least one unseen-boundary prediction.
