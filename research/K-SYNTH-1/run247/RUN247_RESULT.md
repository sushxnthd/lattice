# K-SYNTH-1 Run247 — edit-authority counterexample and hardened compiler

Replacing an authorized method with a new method plus a duplicate read-only sibling declaration (same name/signature) passes the old `symbols()` dictionary check, because duplicate definitions are collapsed by name. Python's last-definition-wins semantics then changes the protected method's result from `ORIGINAL` to `OVERRIDDEN`. A class-body assignment (`protected = lambda self: ...`) gives a second override route.

The locally implemented `trusted_compiler_v4.py` rejects both routes by checking pinned input SHA-256 hashes, lexical declaration multiplicities, new writes to existing declaration names, and exact read-only anchors.
