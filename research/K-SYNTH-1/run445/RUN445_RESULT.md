## New methodological counterexample: joint-success interaction is not cross-file dataflow

A separate **post-outcome exploratory** 2×2 ablation of app and cookie edits produced:

| App edit | Cookie edit | Correct app+cookie observations /256 | Joint-success cases /128 |
|---|---|---:|---:|
| No | No | 128 | 64 |
| No | Yes | 96 | 32 |
| Yes | No | 96 | 32 |
| Yes | Yes | 64 | 32 |

The additive per-API factorial interaction is **zero**, while the joint-success interaction is **+32**. Exact identity: if `J_ab(x)=A_a(x)B_b(x)`, then `I_J = sum_x (A_1-A_0)(B_1-B_0)`. Thus even fully separate API outcomes can yield a large *positive* joint-success interaction, here generated by **two independent regressions** on the same controls. Joint target-plus-control correctness is essential for qualification, but a nonzero joint-score interaction alone is **not proof of cross-file dataflow**. The independent auditor also checked all 512 exploratory factorial rows, totaling **7,980 checks** across both experiments.
