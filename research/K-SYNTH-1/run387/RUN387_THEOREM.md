# Run387 bounded theorem and counterexamples

**Definition-time soundness counterexample.** Run386 admitted `def target(x: missing_name, y): return p(x,y)` and generated a finite effect certificate, but CPython raises `NameError` while defining the function. The equally admitted annotation `x: emit("definition", True)` generates an event at definition time omitted by Run386 traces. Therefore its earlier effect-completeness claim did not cover function-definition observations. The hardened local analyzer rejects annotated arguments as `UNKNOWN: DEFINITION_TIME_ANNOTATION`. 1,024 seeded annotation variants rejected, all 256 historical unannotated certificates unchanged.

**Conditional direct-call binding lemma.** If a direct import binds the analyzed function, neither name is rebound, the function definition completes, and the call supplies only fixed positional arguments and named keywords, Python's simple positional-or-keyword signature binding is decidable with `inspect.Signature.bind`. This claim is *only* about binding shape; annotations, import effects, argument evaluation, reachability, and body semantics remain outside scope. The pinned Rich source pairs give compatible / incompatible / incompatible / compatible. The original stricter checker returned `UNKNOWN` on all four because annotated parameters were present; that failure is preserved.

**Casewise interaction.** For binary correctness, `delta = y_full - y_A - y_B + y_base` can reach +2, when both single-source changes break a previously passing case and the joint change restores it. The separately post-frozen Rich diagnostic observed 2 cases with delta 0, 4 with +1, 10 with +2. This is an API compatibility interaction, not evidence of model representation superiority. Original A/B frozen-oracle processes aborted before per-case scoring.
