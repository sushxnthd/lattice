# Run707 — __future__ directive binding counterexample
UTC date: 2026-11-17. Branch research/exp003-context-order; PR #9 must remain draft/unmerged.

The Run706 alpha wrongly classified `from __future__ import annotations\ndef annotations():\n    pass\n` as UNKNOWN with IMPORT_FUNCTION_BINDING_COLLISION. Python's future directive does not bind the runtime name `annotations`; this was a false refusal, not unsound acceptance. A minimal patch skips binding bookkeeping for ast.ImportFrom with module '__future__' while retaining the compiler-validity check. Three unittest methods passed, including six supported future-feature names, two ordinary import collisions (still UNKNOWN), and invalid late future-directive placement (still UNKNOWN). The tested local implementation and raw logs are in the SHA-verified Run707 local archive. This is a bounded alpha correctness improvement; no production repair or model comparison was performed.
