# Lattice

Lattice studies programming representations designed for AI authorship.

## Immediate research question

> Does typed, executable intent improve long-horizon AI coding beyond equally informative passive project memory and dependency-graph context?

Experiment 001 compares four equal-budget conditions:

1. direct source-code generation,
2. persistent structured project memory,
3. memory plus architecture/dependency graph context,
4. executable Lattice semantics plus deterministic preflight checking.

The first prototype is deliberately small. It tests durable commitments, permissions, legal state transitions, protected dependencies, and executable invariants. Syntax design, UI, and compiler work are deferred until this mechanism beats strong passive baselines.

See `experiments/exp001/protocol.md`.
